Administración

Administración del registro

Esta pantalla es para quienes administran el registro. Deciden qué universidades, colegios, ministerios y hospitales participan. Un médico, una universidad o un hospital no necesitan entrar acá.

Qué es esta sección y cómo se usa

¿Para quién es?

Para el administrador del registro. En un sistema real, cada cambio lo tienen que aprobar varias personas juntas, no una sola.

¿Qué se hace acá?

  • Sumar una institución nueva y decir qué puede otorgar (títulos, matrículas, especialidades).
  • Habilitar a las personas que trabajan para cada institución.
  • Suspender a una institución si deja de estar autorizada.
  • Frenar todo el sistema ante una emergencia, por ejemplo si roban un acceso.

El administrador no puede otorgar, suspender ni dar de baja matrículas: eso solo lo hace la institución que las otorgó.

¿Por qué hay que ingresar?

Porque estos cambios los puede hacer solo el administrador. Cualquiera que ingrese puede ver la lista de instituciones, pero no modificarla.
